# 年年学（nian_learn）

给大约 6 岁儿童、可陪伴到 5–12 岁的学习与陪伴工具。v1 是 Vite + React + TypeScript 的 PWA，学习记录由独立后端写入 PostgreSQL。浏览器只在断网时暂存还没送出的密文，后端才是权威数据源。

儿童可用性测试和育儿专家评估都还没有做。方案在 [docs/可用性测试方案.md](docs/可用性测试方案.md)，状态是待线下执行。

## 怎么访问

需要 Node.js 20 或更新版本。数据库用 PostgreSQL，连接串只从环境变量 `DATABASE_URL` 读取，代码里不写云账号。

本地没有云连接串时，用 Docker 起一个 Postgres：

```bash
cd nian_learn
cp .env.example .env
docker compose up -d
npm install
npm run server
```

另开一个终端启动前端：

```bash
cd nian_learn
npm run dev
```

- 前端：`http://127.0.0.1:5173`
- 后端：`http://127.0.0.1:8787`（健康检查是 `http://127.0.0.1:8787/health`）
- 数据库：`.env` 里的 `DATABASE_URL`。示例是 `postgres://nian:nian@127.0.0.1:5432/nian_learn`，这只给本机 Docker 用。换成云数据库时，只改这个环境变量。

第一次打开前端会请家长设口令。设好后，家长后台里有家庭码。另一台设备选「加入已有家庭」，输入家庭码和同一个口令，就能从后端读回记录。

生产构建和预览：

```bash
npm run build
npm run preview
```

预览地址一般是 `http://127.0.0.1:4173`。构建时同样要有 `VITE_API_URL` 指向后端，开发默认是 `http://127.0.0.1:8787`（写在 `.env.development`）。

## 断网后再同步怎么验

1. 后端和数据库都开着，在前端做一题数学。
2. 刷新页面。完成次数还在。这次是从后端读回的，不是只看浏览器里的旧页面。
3. 关掉网络，再做一题。页面上次数会先增加，数据库里还没有这道新记录。
4. 恢复网络，等首页写着「已写入后端」。
5. 在数据库里查看 `records` 表。新记录的 `ciphertext` 是密文。搜不到刚才的题目、选项和家长口令。表里也没有口令明文，只有家庭码、记录编号、类型、密文、初始向量和更新时间。

可以直接查：

```bash
psql "$DATABASE_URL" -c "SELECT kind, id, left(ciphertext, 24) FROM records ORDER BY updated_at;"
```

## 离线

题目和页面打进资源，也放在可替换的 JSON 内容包里。服务工作线程缓存这些页面资源，不缓存学习记录接口。

没有网络时，英语、数学、语文、心情、习惯、一起玩仍然可以做。刚做完的记录先放在这台设备的待同步缓存里。网络恢复后，客户端把缓存推到后端。刷新或另一台设备打开时，以 PostgreSQL 里的密文为准。

语音用设备自己的 Web Speech 合成，不上传文本。没有语音时，看字和图片也能做完。听写不依赖麦克风。录音即使成功也不会保存，也不会上传。

## 加密与隐私

- 答题次数、心情、习惯、用时和家长规则，在离开浏览器之前用 AES-GCM 加密。后端只存密文、记录编号、家庭码和更新时间。
- 密钥用家长口令经 PBKDF2（SHA-256，12 万次）派生。口令不以明文进入数据库，后端也不保存口令。
- 浏览器只把不可导出的密钥和访问令牌放在 IndexedDB，用来下次解密和调用接口。这不是学习记录的权威副本。
- 没有第三方统计。`src/lib/extensions.ts` 里的同步、成长记录、社交数组是空的，不要往那里接分析服务。社交不做联网聊天。

忘记口令无法找回，程序里没有后门。清除这台设备的网站数据后，要用家庭码和口令重新加入，才能从后端解开记录。家庭码请在家长后台抄下来。

## 家长规则包

家长后台用同一口令进入。里面可以改每天上限、每次时长、休息时间，以及模块开关。默认每天 25 分钟、每次 15 分钟、休息 5 分钟。界面写明建议每天 20–30 分钟，并且可以改。孩子改不了这些数字。

导出的 `nian-learn-rules.json` 只用家长口令做 AES-GCM 加密，里面是时长、开关、年龄段和语音开关，没有学习明细。另一台设备进入家长后台，用同一口令导入，就能套用这套规则。学习记录本身不在这个文件里，而是加密后放在后端。另一台设备用家庭码和同一个口令加入后，从后端读取。

操作步骤见 [docs/家长后台操作指南.md](docs/家长后台操作指南.md)。给家长和孩子看的用法见 [docs/使用手册.md](docs/使用手册.md)。

## 内容包

按季度放在：

```text
src/content/packs/2026-q4/
  manifest.json
  english.json
  chinese.json
  math.json
  emotions.json
  habits.json
  together.json
```

当前季度写在 `public/content/packs/current.json` 的 `packId`。换季时新增目录，例如 `src/content/packs/2027-q1/`，把 `packId` 改成 `2027-q1`。编号必须是 `年份-q季度`，例如 `2027-q1`。

加载入口是 `loadContentPack()`（`src/content/loadPack.ts`）。它先读 `current.json`，再取该季度的 `manifest.json` 和列出的文件；失败时用本机缓存，再不行就用内置的 2026 年第四季度包。数学题不写死在 JSON 里，`math.json` 只提供各年龄的数字范围，题目由 `makeQuestion()` 现生成。

内容是为本应用写的短句和词表，不是教材课文，也没有歌词。

## 以后可以加的部分

年龄注册表在 `src/lib/registry.ts`。学前和一年级已开放。二年级到六年级只留在注册表，首页不显示，也没有空页面。开放新年级时，把对应项的 `enabled` 设为 true，并在内容包里补上该年级的数学范围和拼音范围。

学科注册表里的科学、成长记录、社交同样未开放。不要为它们做占位页。

## 已知限制

- 时长按页面打开、并且人在学习或首页时累计，不是实验室计时。切到后台只会少量计入。
- 不同设备的语音合成声音不一样；有的浏览器要先点一下才出声。
- 清除站点数据、换浏览器或关掉 IndexedDB 后，需要家长口令才能再打开；若加密包也没了，记录无法恢复。
- 规则包不会同步学习记录。
- 儿童实测和专家评估尚未执行，不能把本说明理解成已经验证或已经认证。
