# 年年学（nian_learn）

给大约 6 岁儿童、可陪伴到 5–12 岁的学习与陪伴工具。v1 是一套 Vite + React + TypeScript 的 PWA：竖屏手机和横屏平板用同一套界面，核心学习在没有网络时也能完成。

儿童可用性测试和育儿专家评估都还没有做。方案在 [docs/可用性测试方案.md](docs/可用性测试方案.md)，状态是待线下执行。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
cd nian_learn
npm install
npm run dev
```

浏览器打开终端里的本地地址（一般是 `http://127.0.0.1:5173`）。第一次会请家长设口令。

生产构建和预览：

```bash
npm run build
npm run preview
```

预览地址一般是 `http://127.0.0.1:4173`。

## 离线

学习内容打进页面资源，也放在可替换的 JSON 内容包里。服务工作线程会缓存页面和内容包。

建议第一次用网络打开一次，让浏览器装好缓存。之后关掉网络，刷新页面，英语、数学、语文、心情、习惯、一起玩、时长和家长规则仍然可用。语音用设备自己的 Web Speech 合成，不上传文本。没有语音时，看字和图片也能做完。

听写不依赖麦克风。没有麦克风、拒绝授权或没有网络时，用「听音选图」和「我说对了」自评，不会卡在录音上。录音即使成功也不会保存，也不会上传。

## 加密与隐私

- 儿童的学习记录、习惯连续天数、用时，用 AES-GCM 加密后放在本机 `localStorage`。
- 密钥用家长口令经 PBKDF2（SHA-256）派生，再包住一把数据密钥。口令和原始密钥不以字符串写入存储。
- 浏览器把不可导出的数据密钥放在 IndexedDB，方便孩子下次直接打开。这不是明文口令。
- 没有云账号，没有第三方统计，也不会上传儿童的答题、心情或录音。
- `src/lib/extensions.ts` 里留了同步、成长记录、社交接口，v1 都是空的。社交不做联网聊天。

忘记口令无法找回，程序里没有后门。清除网站数据会丢掉这台设备上的记录。

## 家长规则包

家长后台用同一口令进入。里面可以改每天上限、每次时长、休息时间，以及模块开关。默认每天 25 分钟、每次 15 分钟、休息 5 分钟。界面写明建议每天 20–30 分钟，并且可以改。孩子改不了这些数字。

导出的 `nian-learn-rules.json` 只用家长口令做 AES-GCM 加密，里面是时长、开关、年龄段和语音开关，没有学习明细。另一台设备进入家长后台，用同一口令导入，就能改那边的规则。学习记录仍留在各自设备上。

操作步骤见 [docs/家长后台操作指南.md](docs/家长后台操作指南.md)。给家长和孩子看的用法见 [docs/使用手册.md](docs/使用手册.md)。

## 内容包

按季度放在：

```text
src/content/packs/2026-q4/
  manifest.json
  english.json
  chinese.json
  math.json
  emotions.json
  habits.json
  together.json
```

当前季度写在 `public/content/packs/current.json` 的 `packId`。换季时新增目录，例如 `src/content/packs/2027-q1/`，把 `packId` 改成 `2027-q1`。编号必须是 `年份-q季度`，例如 `2027-q1`。

加载入口是 `loadContentPack()`（`src/content/loadPack.ts`）。它先读 `current.json`，再取该季度的 `manifest.json` 和列出的文件；失败时用本机缓存，再不行就用内置的 2026 年第四季度包。数学题不写死在 JSON 里，`math.json` 只提供各年龄的数字范围，题目由 `makeQuestion()` 现生成。

内容是为本应用写的短句和词表，不是教材课文，也没有歌词。

## 以后可以加的部分

年龄注册表在 `src/lib/registry.ts`。学前和一年级已开放。二年级到六年级只留在注册表，首页不显示，也没有空页面。开放新年级时，把对应项的 `enabled` 设为 true，并在内容包里补上该年级的数学范围和拼音范围。

学科注册表里的科学、成长记录、社交同样未开放。不要为它们做占位页。

## 已知限制

- 时长按页面打开、并且人在学习或首页时累计，不是实验室计时。切到后台只会少量计入。
- 不同设备的语音合成声音不一样；有的浏览器要先点一下才出声。
- 清除站点数据、换浏览器或关掉 IndexedDB 后，需要家长口令才能再打开；若加密包也没了，记录无法恢复。
- 规则包不会同步学习记录。
- 儿童实测和专家评估尚未执行，不能把本说明理解成已经验证或已经认证。
